# Plotting

Matplotlib exercises for the Mathematics for Machine Learning module.

## Files

| File | Description |
| --- | --- |
| `0-line.py` | Plots y = x^3 as a solid red line |
| `1-scatter.py` | Scatter plot of men's height against weight |
| `2-change_scale.py` | C-14 decay with a logarithmic y-axis |
| `3-two.py` | C-14 and Ra-226 decay on shared axes with a legend |
| `4-frequency.py` | Histogram of student grades, bins every 10 units |
| `5-all_in_one.py` | All five plots in a single 3x2 figure |
| `6-bars.py` | Stacked bar graph of fruit per person |

## Requirements

Python 3.5 on Ubuntu 16.04, numpy 1.15, matplotlib 3.0, pycodestyle 2.5.

## Usage

    ./0-line.py
