# Bayesian Probability

Mathematics for Machine Learning project at ALU.

| File | Description |
| ---- | ----------- |
| `0-likelihood.py` | binomial likelihood of the data for each hypothetical probability |
| `1-intersection.py` | likelihood multiplied by the prior |
| `2-marginal.py` | marginal probability of the data |
| `3-posterior.py` | posterior probability given the data |
