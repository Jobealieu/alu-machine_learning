# Linear Algebra

Mathematics for Machine Learning, project `math/linear_algebra`.

Vector and matrix operations, first in pure Python (no imports allowed),
then with NumPy.

## Environment

Ubuntu 16.04, python3 3.5, numpy 1.15, pycodestyle 2.5.
Every file is executable, starts with `#!/usr/bin/env python3`, ends with
a newline, and carries module and function docstrings.
